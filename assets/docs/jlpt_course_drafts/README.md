# 猫语 N4、N3 原创试点课程

N4 已按大纲编写 16 个单元、96 节试学课，从餐厅深化到综合应用。每单元包含词汇、语法、阅读、听力、输出、迁移应用六类课，另有独立单元练习。等级综合练习含 8 道阅读、8 道听力与 1 个口语和写作任务。N3 现有第一个单元「职场日语」6 节，规划总量为 20 单元、120 节。等级是 JLPT 参考。

课号和顺序沿用 `opencode-course-allocation-20261104@01c6e00` 的 `docs/NEKOGO_MAIN_LESSON_ALLOCATION_20261104.md`。

## 数据和审校交接

- 词表、中文讲解、日语例句、练习、检查、角色卡及反馈为本次 AI 原创草稿。未导入第三方词表、教材、真题或录音。词表给出词形、假名与中文义项，阅读例句把汉字放在实际通知或消息中。日语自然度、汉字与读音覆盖、教学设计和权利均待人工审校。
- 参考 `opencode-course-batch4-20261104@c0e3429` 的 N5 数据字段与引用。T 课和 O/T 人工量规留在草稿中，待统一引擎确认生产结构。课号是规划键，`draft.*` 用于草稿内部引用，生产映射由集成方确认。先修只作为学习顺序建议。
- R 检查先展示日文素材及题目，答后用反馈讲解。L 目前只有分角色脚本，待制作、审校及验证可听音频，届时检查前只播放声音，答后再展示脚本与反馈。O/T 以角色卡和人工量规练习，不自动计分。
- 客观题记录题目 ID、目标和词汇引用，供接入时定位错题和反馈。试学检查使用统一练习引擎保存断点，交卷后把错题加入错题本。正式课程资产仍需按生产契约迁入。当前 App 可按下文方式打开 N4 全部试学课和 N3 首个单元。
- 上线前需审定题量与等级测评标准，审核原料询问等场景的表达，逐题排除可见答案提示，并确认词汇、语法、汉字、听读覆盖和授权记录。Flutter 与设备验收留给用户本地。

## 单元测接入

`exam.materials` 保存全新阅读材料和录音脚本，`exam.reading`、`exam.listening` 沿用 N5 的题目、素材及教学目标引用，`exam.output` 保存人工任务和量规。单元练习使用与教学和课内练习不同的材料。

阅读开始时仅展示对应日文材料、题干与选项。听力开始时只展示题干、选项和音频入口，录制脚本供内容团队使用，答后才向学习者展示。答案与反馈仅在提交后展示；本目录的完整 JSON 供编辑和接入，不能直接作为学生端作答视图。当前没有音频、上线阈值或通过判定。正式接入后按题目 ID 将错题关联到教学目标。

## App 本地试学

运行 `flutter run --dart-define=NEKOGO_N4_PILOT=true` 后，在「学习」按等级打开「JLPT 课程试学」。N4 的 96 节和 N3 首单元的 6 节都能打开。词汇、语法和阅读课可以答题，口语、写作和迁移课提供任务卡及自查要点，听力课用系统日语朗读做题，朗读失败时可看文字作答。每个单元另有阅读测验、听力练习和口语与写作任务。系统朗读供试学，正式听力音频仍待制作和审校。试学只保留最近开始答题的一课的断点。从同一节课回来可以续答，完成后清除该断点。

验证命令为 `flutter test --dart-define=NEKOGO_N4_PILOT=true test/n4_pilot_resume_test.dart`。

本地文本审校修订了 N4-02 的巴士听力题、N4-04 与 N4-16 的说话人指代，以及等级阅读第 2 题的集合地点。听力题和选项现在可凭对话作答，避免依赖系统朗读时省略的 A/B 标签。题目 ID 保持原样。此轮只核对文本与试学流程，录音听审和正式上线验收仍待完成。

听力检查支持在素材对象里填写已获分发授权的 HTTPS `audio_url`。同一次检查用到的每段素材都要有录音地址。全部没有地址时继续使用试学朗读，录音配置不完整时显示内容不可用。录音播放完成后才会出现「我已听完」，播放失败可以重试或跳过。当前 N4 草稿仍没有正式录音地址。

听力课的教学示例、课内练习及错题重练也读取对应素材的 `audio_url`。配置录音的练习题由学习者点喇叭播放，避免网页自动播放限制。练习和重练播放失败时可看文字作答，听力检查仍要求听完才能作答。

N4 听审完成后，用 `python3 tools/bind_n4_recordings.py <听审包解压目录> <导出的审校结果.json> <录音HTTPS目录> <新的输出目录>` 生成带录音地址的课程文件。脚本会逐段核对审校人、通过状态、音频哈希及课程原稿，只在新目录输出文件。正式发布前仍需在实际部署地址核对录音可访问、返回的文件与听审包一致，并保留听审包中的音色署名。工具会把两种 HTS 音色的署名和许可写进课程配置，有录音的课可在「录音来源与许可」查看。

N4-01-L03 的独立阅读检查包含一道完形题。题目用 `type: "cloze"`，独立素材中只放一个 `〔空〕`；现有选择题可省略 `type`。答题时保留空格，交卷后解析填入正确选项。
