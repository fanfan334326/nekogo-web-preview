# N5 现有试学课程机器初审

逐项读取当前16单元、80节课的词表、目标、讲解、教学／练习／检查材料、题目、反馈、角色卡及人工量规。范围包括115组词条、237条选择题数据和15份独立输出任务。237条包含尚未开放的听力题及输出课保留的参考选择题，不代表237道题已在正式入口开放。本轮不新增课程或题量，不扩大正式入口，不将机器初审记作人工审校。

## 情境没有传到页面

N5-04 的指物题依赖说话者、听者和物品的相对位置。资料已有context_zh，但教学、练习、独立检查和错题复练只提取jp，学生看不到题设位置。新增widget测试在旧代码下先因教学情境未显示而失败。

现由共用材料呈现函数保留情境，独立阅读检查把情境放在标题区，日文原文及原文依据保持原样。教学、练习、独立检查、错题复练和原课语法提示均保留情境。中文情境不加入朗读输入；听力检查不借此显示原稿。

N5-02 的人物题还使用中文译名提问、以中文译名作选项，日文材料却只有假名，例如ユナ／マキ／トワ与由奈／真纪／永久。它们不是可以仅凭假名唯一推导的姓名汉字。现补本课虚构译名表，只列名字对应，不给人物关系、年龄或身份答案。N5-11、N5-13的类似译名也作相同处理。保留原选项和答案，已有续答选择无需因改名失效；尚未开放的听力材料中的译名说明只是待审数据，不声称已通过听审或已在听力页面呈现。

## 教学与任务对应

N5-01 的问候顺序限定为本课示例，不再说成所有初见的固定顺序。补充已有材料或输出任务实际使用、此前未讲清的词语和句型：N5-10暖かい，N5-11游泳／弹吉他／网球、每周与否定喜好／低频率表达，N5-12楼层及询问可否休息的固定表达，N5-13自己的兄弟姐妹称谓，N5-15京都和おみやげ。N5-14说明现有つもり句型前的普通形及行く／勉強する示例，避免把ます直接接在つもり前。N5-11语法目标改为“活动频率”，不把よく说成具体间隔次数。

句型核对参考国际交流基金[つもりです说明](https://www.kyozai.jpf.go.jp/kyozai/material/BMA00032/ja/render.do)及[《いろどり》初级1第14课第19页](https://www.irodori.jpf.go.jp/assets/data/elementary01/pdf/Y_L14.pdf)。仅核对常体非过去接续、て形许可请求等用法，修订文字自行组织；没有导入外部教材正文，不以核对参考替代原始内容授权记录。

输出任务修正：N5-04说清扮演角色及双方位置，课内检查只要求每个渠道一组だれの问答，自查不再误要求两组；独立单元任务仍保留原来的两组要求。N5-05练习点茶／面包、检查点米饭／水，分别核对。N5-10练习仅谈今天，检查才谈今天和明天。N5-11检查没有提问要求，自查不再额外要求问句。N5-14练习原要求确认时间地点但卡片未提供，现补周日下午三点及电影院门口。N5-15练习是一件做了、一件没做，检查才是两件做了、一件没做，分别核对。人工评分方式、原有分值和阈值均保留，未自动评分。

听力题把未必会朗读的A/B标签改为可凭对话定位的说话行为，例如“先开口自我介绍的人”“被问国籍的人”“答应一起看电影的人”。其余课内及单元阅读／听力题逐句核对原稿和答案，没有改判答案。该核对仅针对文字，不证明录音中的角色可辨。
